`@enbox/browser` is the package entrypoint for browser dapps. It re-exports the
application API from `@enbox/api`, the browser-safe auth surface, and the wallet
connect and DWeb utilities.

```bash
bun add @enbox/browser
```

Follow [Build a browser dapp](/docs/guides/browser-dapp) for the complete
application scaffold. It is the canonical source for connection-store usage,
the required service worker, live records, offline behavior, and deployment.

[Browser package behavior](/docs/guides/browser-bundlers) documents conditional
exports, lower-level imports, and persistent storage.

## Key exports

| Export | Description |
|---|---|
| `Enbox` | High-level application API from `@enbox/api` |
| `createConnectionStore()` | Application connection lifecycle and observable snapshots |
| `defineProtocol()` | Typed protocol definition helper |
| `recordCodecs` | JSON, text, bytes, Blob, and private-file envelope codecs |
| `AuthManager` | Lower-level auth/session lifecycle |
| `BrowserConnectHandler` | Browser wallet connect handler |
| `connectViaPopup()` | Low-level DWeb Connect popup handshake |
| `activatePolyfills()` | DRL and DWeb browser feature activation |
| `runConnectModal()` | Built-in wallet/connect method selector |
